# Complementos manuais da Entrega 03

Estes itens precisam ser produzidos pela equipe após executar a aplicação. Não foram simulados neste repositório.

## Vídeo do sistema

1. Inicie a aplicação com `mvn spring-boot:run`.
2. Cadastre um paciente e um médico, agende uma consulta e mostre a confirmação de presença.
3. Agende outra consulta e cancele-a, informando o motivo; mostre o status `CANCELADA` e o motivo salvo.
4. Publique o vídeo no YouTube com áudio ou legendas e substitua o marcador correspondente no README pelo link real.

## Vídeo do código

1. Mostre `AppointmentService`, explicando as regras de confirmação e cancelamento.
2. Mostre as entidades JPA e os repositórios, destacando que as mudanças persistem no banco H2.
3. Publique com áudio ou legendas e substitua o marcador correspondente no README pelo link real.

## Issues e captura

1. Crie issues reais no GitHub para tarefas/bugs encontrados durante a entrega e atualize-as semanalmente.
2. Faça uma captura autêntica da página de Issues mostrando a atividade.
3. Salve a imagem em `docs/entrega-03/evidencias/issues-entrega-03.png` e substitua o marcador no README.

Não use imagens, links ou registros inventados como evidência.
